# Manuales de las suites del hotel

Estos manuales explican, en lenguaje sencillo, el trabajo diario del personal con las suites de la
plataforma. Cada uno incluye **Empezar en 5 minutos**, pasos numerados, una infografía y qué hacer si
algo falla.

| Manual | Para quién |
|---|---|
| [01 · Mantenimiento](01-mantenimiento.md) | Jefe de mantenimiento y técnico |
| [02 · Ama de llaves](02-ama-de-llaves.md) | Jefa de ama de llaves y camareras |
| [03 · Suministros y SLA](03-suministros-y-sla.md) | Jefa de ama de llaves y administración |
| [04 · Daños y reclamaciones](04-danos-y-reclamaciones.md) | Recepción, ama de llaves y huésped |
| [05 · Gobernanza y firmas](05-gobernanza-y-firmas.md) | Propietario/administrador y soporte |
| [06 · Recepción vNext](06-recepcion-vnext.md) | Recepcionista |
| [07 · Terminal con PIN](07-terminal-pin.md) | Técnicos y camareras |

**Descarga:** cada manual tiene su PDF en `docs/pdf/manual-<slug>.pdf` y en la web (`/ayuda`). Las
infografías se generan desde `docs/imagenes/doc-suite-*.svg` y se muestran también dentro del manual.
